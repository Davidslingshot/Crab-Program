# 蟹卡提货小程序

这是一个基于微信小程序的蟹卡提货系统，包含用户端和管理端，支持后端服务器数据存储。

## 项目结构

```
miniprogram-7/
├── server/                 # 后端服务器
│   ├── data/              # 数据存储目录（自动生成）
│   │   ├── cards.json     # 卡片数据
│   │   └── orders.json    # 订单数据
│   ├── server.js          # 服务器主文件
│   ├── package.json       # 依赖配置
│   ├── start.bat          # Windows启动脚本
│   └── README.md          # 服务器说明文档
├── pages/                 # 小程序页面
│   ├── index/             # 首页
│   ├── login/             # 用户登录
│   ├── pickup/            # 提货申请
│   ├── order/             # 订单查看
│   └── admin/             # 管理端
│       ├── login/         # 管理员登录
│       ├── orders/        # 订单管理
│       └── cards/         # 卡片管理
├── utils/                 # 工具函数
│   ├── api.js             # API接口封装
│   └── storage.js         # 本地存储工具（已废弃）
├── app.js                 # 小程序入口
├── app.json               # 小程序配置
└── project.config.json    # 项目配置
```

## 快速开始

### 1. 启动后端服务器

**Windows系统：**
```bash
cd server
start.bat
```

**Mac/Linux系统：**
```bash
cd server
npm install
npm start
```

服务器将在 `http://localhost:3000` 启动

### 2. 配置小程序

1. 使用微信开发者工具打开项目
2. 在 `utils/api.js` 中配置服务器地址（默认为 `http://localhost:3000`）
3. 编译运行小程序

## 功能说明

### 用户端
- **蟹卡登录**：输入卡号和密码验证蟹卡
- **提货申请**：填写收货信息提交提货申请
- **订单查看**：查看已提交的订单状态

### 管理端
- **订单管理**：查看所有订单，更新订单状态
- **卡片管理**：查看所有卡片，批量导入新卡片
- **数据导出**：导出订单数据为CSV文件

## 数据存储

- **后端服务器**：数据存储在 `server/data/` 目录下的JSON文件中
- **小程序本地**：仅存储当前登录的卡片信息和管理员登录状态

## 注意事项

1. **必须先启动后端服务器**，小程序才能正常使用
2. 修改服务器端口时，需要同步修改 `utils/api.js` 中的 `BASE_URL`
3. 建议定期备份 `server/data` 目录下的数据文件
4. 如果使用真机调试，需要确保手机能访问到服务器地址

## 常见问题

### Q: 小程序提示"网络错误"？
A: 检查后端服务器是否已启动，并确认 `utils/api.js` 中的服务器地址配置正确。

### Q: 订单数据丢失？
A: 确保使用的是后端服务器版本，数据存储在服务器的JSON文件中。

### Q: 如何修改服务器端口？
A: 修改 `server/server.js` 中的 `PORT` 变量，并同步更新 `utils/api.js` 中的 `BASE_URL`。
